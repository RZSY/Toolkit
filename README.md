## What is Toolkit?

Toolkit is a collection of small web-based programs and utilities that I have either made myself or found useful enough to put together in one place.

The idea is pretty simple:

**Why do something manually when I can make a program do it for me?**

This repository contains various tools intended to make everyday academic, technical, creative, and general-purpose tasks a little less annoying.

Some of these tools were made because I needed them. Others were made because I thought, *"Surely there is a better way to do this."*

And sometimes the better way was to spend several hours making a tool that saves approximately five minutes.

That's programming, I guess.

---

# Why I Made This

I originally had this idea near the beginning of my **Diploma**.

There were quite a few things that I kept doing manually, particularly when it came to making graphs, processing information, converting things, formatting data, and doing other repetitive tasks.

At some point I thought:

> "I'm getting tired of doing this manually."

So naturally, instead of continuing to do it manually, I decided to make programs to do it for me.

Unfortunately, I only properly entertained the idea during the **last semester of my Diploma**.

Which was, admittedly, a little late.

By the time I had the idea properly developed, there wasn't much Diploma work left to use it for.

But that's fine.

It may have been too late for Diploma use, but it is **not too late for Degree use**.

So Toolkit lives.

# The Philosophy

Toolkit is built around a fairly simple philosophy:

### If something is repetitive, automate it.

### If something is annoying, simplify it.

### If something doesn't exist, make it.

### If something already exists but is unnecessarily complicated, make a simpler version.

### If something already exists but I don't know it exists, make it.

This repository isn't intended to compete with massive commercial software suites.

It's a personal toolbox.

If something here saves me time, then it has already served its purpose.

If it happens to save someone else's time too, even better.

# Adding New Tools

One of the advantages of Toolkit being a collection of relatively independent tools is that new ones can be added over time.

If I encounter another repetitive task that annoys me enough, there's a decent chance it'll eventually end up here.

The general process is:

1. Make the tool.
2. Test the tool.
3. Add it to the Toolkit interface.
4. Use it myself.
5. Fix whatever I inevitably broke.
6. Repeat.

# Contributions

Contributions are welcome.

If you have an improvement, bug fix, new tool, or genuinely good idea, feel free to open an issue or submit a pull request.

That said, this is primarily a personal project, so not every suggestion will necessarily be implemented.

If you want to contribute, please try to keep additions consistent with the general philosophy of the project:

* Keep things simple.
* Keep things useful.
* Avoid unnecessary dependencies.
* Avoid unnecessary complexity.
* Don't add features just because they sound impressive.
* Make sure the thing actually works.

# Issues and Bug Reports

Found something broken?

Please report it.

When reporting a bug, it helps to include:

* What you were trying to do
* Which tool you were using
* What you expected to happen
* What actually happened
* Your browser and operating system, if relevant
* Any error messages you encountered

Screenshots are also appreciated when applicable.

"Doesn't work" is technically a bug report, but it doesn't give me much to work with.
